# SnapRecover

A beautiful landing page + working recovery tool UI for recovering old Snapchat DMs and messages.

Built with **Vite + React + TypeScript + Tailwind CSS v4 + Framer Motion**.

## Features

- Dark, neon Snapchat-themed landing page (hero, stats, features, how-it-works, FAQ)
- Working recovery tool UI: enter a username → animated scan flow → preview of recovered chats
- Fully on-device demo (nothing is uploaded)

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Scripts

| Command         | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Start the dev server     |
| `npm run build` | Type-check + production build |
| `npm run lint`  | Run Oxlint              |
| `npm run preview` | Preview the production build |
