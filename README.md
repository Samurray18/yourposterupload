# Snapchat+ Gifter

A beautiful landing page for gifting Snapchat+ subscriptions to friends.

Built with **Vite + React + TypeScript + Tailwind CSS v4 + Framer Motion**.

## Features

- Dark, neon Snapchat-themed landing page (hero, stats, features, how-it-works, FAQ)
- Working gifter tool UI: enter username → pick plan (1/3/6/12 months) → add gift message → animated gifting flow → success with gift ID
- Premium Snapchat+ gifter demo (secure payment simulation)

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Scripts

| Command         | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Start the dev server     |
| `npm run build` | Type-check + production build |
| `npm run lint`  | Run Oxlint              |
| `npm run preview` | Preview the production build |
